# AnnotAgent 品牌规范

## 1. 品牌层级

- **AnnotAgent**：Core Runtime 与唯一全局产品品牌。
- **Domain Skill**：使用 badge、descriptor 和标签映射扩展 Core，不拥有全局产品界面。
- **Example Application**：可以组合 Core 与 Skill 的示例 lockup，但只能用于对应 Project、示例或历史材料。

## 2. Logo 含义

- 中心 `A`：AnnotAgent；同时形成向上的工具/决策结构。
- 四个角：检测框、画布视野和可编辑标注。
- 蓝、青、紫渐变：模型推断、确定性工具、人工复核之间的连续流程。

## 3. Logo 使用

- 浅色背景使用 `annotagent-lockup-light.svg`。
- 深色背景使用 `annotagent-lockup-dark.svg`。
- 64px 以下只使用 mark，不使用长副标题。
- Logo 最小留白：至少为 mark 边框线宽的 4 倍。
- 不拉伸、不旋转、不加外发光、不重新着色、不把足球塞进 Core mark。
- 渐变只用于品牌标志和少量 hero 装饰；功能按钮和状态使用纯色。

## 4. 文案层级

推荐 descriptor：

- Core：`Agentic annotation · auditable by design`
- 通用产品：`Composable annotation workflows for vision data.`
- RoboCup Skill：`VLM-assisted annotation and quality control for robot soccer perception`

产品 UI 内不要反复放营销 slogan。界面首先是工具，不是机场广告牌。

## 5. 色彩角色

- Ink / Navy：可信、技术、操作背景。
- Primary Blue：主操作、选中状态和导航焦点。
- Teal：验证、工具执行和品牌强调。
- Violet：Agent intelligence、扩展 Skill 和次级品牌强调。
- 语义红黄绿只用于状态，不承担品牌装饰。

## 6. 字体

- UI：Inter，fallback 为系统 sans-serif。
- 代码、Token、trace：JetBrains Mono，fallback 为系统 monospace。
- 不在仓库中提交字体文件，除非项目单独确认授权和分发方式。
