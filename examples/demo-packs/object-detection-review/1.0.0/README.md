# 标注桌面物品

6 张原创合成图片，类别为 `cup` 和 `bottle`，训练用途为 Ultralytics YOLO
目标检测数据包。图片在仓库内离线可用，不需要下载外部素材。

包含：

- 单杯和单瓶的大目标图片；
- 同时包含杯子和瓶子的多目标图片；
- 一张确认没有目标的图片；
- 一张用于解释边界修订的图片；
- 固定的 4 张训练集、2 张验证集划分，两侧都覆盖 `cup` 和 `bottle`。

所有图片均为 **synthetic / 程序化合成插图**，不是摄影数据或模型生成的
检测结果。详细来源与许可见 [ATTRIBUTION.md](ATTRIBUTION.md)。

## 两种体验模式的文案

### 用我的模型试跑

使用你已经配置并批准的模型处理这 6 张图片。开始前显示将发送的数据、
模型、调用上限和已知或未知费用；结果来自本次实际调用。若模型未配置，
进入已有模型准备流程，返回同一个待启动任务，不切换到预置候选。

### 免配置体验：预置候选

使用随示例提供的候选，不发生本次模型推理。你可以检查、修改并在审核
齐全后生成数据包。预置候选不是现场识别结果，也不代表你已经接受标注。

## 示例目标

> 请标出这 6 张图片里的杯子和瓶子，准备 Ultralytics YOLO 检测数据。
> 边界不确定时让我确认，审核齐全后打包。

这是“你选择的示例目标”，不是伪造的历史用户消息。图片范围、标签规则和
训练用途已由示例给齐，用户仍可在开始前修改。

## 完成状态

只有服务端数据包状态为 Ready 且 ZIP 可读取时，才显示“数据集已打包”。
结构检查通过不表示标注精度通过；本示例也不执行模型训练。
