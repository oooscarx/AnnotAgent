# Generic Object Detection example

This Project enables only `annotagent.object_detection`; it has no RoboCup dependency. In the Web
Workflow page choose **Trained detector with review**, map a real model class to the `target`
Project Label, Dry Run, and publish.

Use `mock-object-detector` for the offline path. To use a specialist HTTP model, configure and test
the versioned Worker under Settings/Models, then select that registered model binding in the Draft.
