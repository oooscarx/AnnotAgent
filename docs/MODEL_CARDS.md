Last audited: 2026-09-03 CST

## Prompted Segmentation Fixture 1.0.0

**Bundle ID:** `org.annotagent.models.fixture-prompted-segmentation`

**Status:** Built-in, offline, verified, non-publishable Fixture.

This Bundle contains two tiny ONNX graphs generated by AnnotAgent's Rust catalog crate. It contains
no SAM or third-party weights. The real `org.annotagent.sam-onnx` Rust Plugin loads both graphs with
ONNX Runtime, performs sample inference and produces a typed `MaskSet`. The fixed lifecycle test
continues through `Mask to BBox` and `Geometry Quality Evaluation`, then disables and removes the
unreferenced Bundle.

The Fixture exists to prove:

- deterministic `.annotmodel` pack and verification;
- content-addressed installation;
- multi-file Contract inspection;
- Plugin role binding and process startup;
- real ONNX Runtime execution;
- fixed Smoke Test evaluation and Artifact lineage;
- Geometry Safety integration;
- removal and Registry recovery.

It does **not** prove segmentation accuracy, is not SAM, and cannot be selected by or frozen into a
Published Workflow. A `Ready` Fixture instance means only that the provisioning mechanism is
healthy.

**License:** MIT, generated by AnnotAgent contributors. The complete license and source notice are
inside every generated Bundle.

**Geometry semantics:** `RefinedGeometry`.

**Calibration:** `Uncalibrated`; downstream Geometry Quality and Human Review requirements remain
in force.

## EfficientSAM-Ti ONNX

**Status:** `live-conditional`; source and license audited, not published as a supported AnnotAgent
Bundle.

The official [EfficientSAM repository](https://github.com/yformer/EfficientSAM) is Apache-2.0 and
states that its checkpoints are in the repository. Its README links the ONNX encoder/decoder Space
maintained under EfficientSAM author Yunyang Xiong's account. That Space declares Apache-2.0 and
publishes these immutable file identities at revision
`d8dbb1eee73bfb3392aa6f6e8944aeb13f3f4036`:

| Role | Official asset | Size | SHA-256 |
| --- | --- | ---: | --- |
| image encoder | `efficientsam_ti_encoder.onnx` | 24.8 MB | `84ed466ffcc5c1f8d08409bc34a23bb364ab2c15e402cb12d4335a42be0e0951` |
| mask decoder | `efficientsam_ti_decoder.onnx` | 16.6 MB | `a62f8fa5ea080447c0689418d69e58f1e83e0b7adf9c142e2bd9bcc8045c0b11` |

The upstream ONNX exporter uses opset 17. Its split Contract is not the current SAM ViT-B Plugin
Contract: the encoder accepts dynamic `batched_images`; the decoder accepts `image_embeddings`,
`batched_point_coords`, `batched_point_labels` and an `int64 orig_im_size`, and returns
`output_masks` plus `iou_predictions`. The current Plugin expects SAM-specific preprocessing,
`input_image`, `point_coords`, `point_labels`, `mask_input`, `has_mask_input`, float
`orig_im_size`, and `masks`.

AnnotAgent therefore does not rename or force these files into the SAM ViT-B Bundle. Shipping
EfficientSAM requires a versioned EfficientSAM Plugin Contract, a reproducible `.annotmodel`
published from those exact bytes, a fixed real-image Smoke Test, numerical validation and hosted
Catalog identity. Until those artifacts exist, no install button or Ready Model Profile claims
EfficientSAM support.

## SAM 2 / SAM 2.1

**Status:** Labs; no verified AnnotAgent Bundle.

Meta's [official SAM 2 repository](https://github.com/facebookresearch/sam2) states that its code and
checkpoints are Apache-2.0. The audited repository does not provide the complete, fixed split ONNX
Contract required by the current Rust Plugin and Bundle verifier. A PyTorch checkpoint plus an
unofficial converter is not a supported Bundle. SAM 2 stays in Labs until official asset identity,
Rust-loadable ONNX files, Contract, fixed hashes, Smoke Test and Plugin compatibility are all
verified together.

## Safety statement

Installing a prompted-segmentation model never implies geometry correctness. Every supported model
must remain `RefinedGeometry / Uncalibrated` until project-scoped calibration evidence exists.
Coarse boxes, refined masks and derived boxes retain subject lineage, and geometry evaluation or
Human Review may still block Commit.
