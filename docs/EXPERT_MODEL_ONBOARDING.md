# Expert Model Onboarding

Use **Settings → Expert Model Plugins → Install package**. Inspect and approve the deterministic
`.annotplugin`, provision each exact checkpoint component, run the installed-process test and enable
the version. NeedsWeights, Disabled, FailedSmokeTest and UnsupportedPlatform models remain visible
but unavailable to Automation.

See [Rust Model Plugins](RUST_MODEL_PLUGINS.md) for the complete flow. Historical HTTP endpoint
onboarding is archived under [`docs/legacy/python-workers/`](legacy/python-workers/).
