# 任务与交付范围

本稿用于本轮集成文档，功能基线与截图版本分别记录，不能用截图版本代替最终应用 SHA。

## 三个输入

图片范围、标注规则、训练用途保存为 TaskDeliveryIntent。当前界面可补齐缺失项，也可重新编辑；不是一句自然语言必然解析出所有准确字段。保存意图不等于批准模型调用、发布或正式运行。Agent 规划模型与各视觉节点模型分开选择。

LLM 草稿、模板与 Runtime 保底是不同来源。请看实际 Builder 回执及执行轨迹；不因流程中存在节点就宣称执行过。本文真实足球截图对应历史样例，不作为最新集成链路的端到端验收。

## 人工协助

- 样例反馈：绑定样例图片和候选，用于诊断或修正样例；不是正式数据接受。
- 正式对象审核：修改边框、补充遗漏对象、接受或拒绝具体标注；保留来源和修订。
- 整图确认：在对象审核之外声明完整、负样本或排除。无框不能自动解释为负样本。

正式结果应来自当前任务绑定的运行范围。服务端和 UI 的最终统一接线以 Frontend 1 指定集成 SHA 为准。

## 导出范围

标注文件导出支持 Native、COCO、YOLO、LabelMe 的兼容子集。完整包当前只支持 Ultralytics YOLO detection v1。代码生成的真实目录包括：

```text
images/train/…       images/val/…
labels/train/…       labels/val/…
data.yaml
README.md
annotagent/manifest.json
annotagent/split-manifest.json
annotagent/exclusions.json
annotagent/validation-report.json
```

此清单是导出器契约，不是假装已解压某个真实足球包；实际包也可能保留已有 test 划分。原图按原始字节保存；TXT 坐标归一化，类别编号取冻结映射。结构检查涵盖范围、映射、图标配对、文件 hash、划分与审核确认。没有运行 Ultralytics 正式训练或框架加载测试，就不能写成训练验证通过。

包须满足审核、划分和来源等条件。自动打包预授权的应用/存储机制与 HTTP、最后审核触发属于不同层；不把局部代码存在写成完整自动流程已接通。

## 模型与隐私

需要自己配置 Provider 与凭证，或安装兼容 Plugin 和权重。外部调用前核对数据范围、模型、价格；usage 缺失或费用未知不能当作免费。模型 Ready 是安装/契约检查状态，推理与精度要看单独证据。

独立历史分支已实现上下文 JSON 归档，但尚未计入本轮集成 README 的能力承诺。其语义是隔离的只读历史载入；不恢复预算、授权、队列或自动执行。停止回执可能仍是未知结算，重启不等于可以重新发送同一请求。
