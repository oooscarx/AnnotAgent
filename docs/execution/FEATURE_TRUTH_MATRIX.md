# AnnotAgent Feature Truth Matrix

Last audited: 2026-09-04

This matrix records what a visible control actually does. A control is `ready` only when its prerequisite, server side-effect, persistence, refresh recovery, and error path are represented honestly. `labs` is visible but explicitly experimental/read-only, `hidden` is an implemented API without a normal product control, and `remove` means the misleading control is absent.

## Audit conclusions

- Final Results, sandbox Sample Test inspection, Run Debug, and formal Review are separate surfaces with different persistence semantics.
- Exact progress is shown only when the server supplies completed and total image counts; a single Image Run uses an indeterminate progress indicator while active.
- Node/model choices are filtered by the node's capability contract. Human-readable names come from Registry metadata, with identifier humanization only as a fallback.
- Unreleased free-form graph mutation and an operating-system “Open folder” action are not advertised as working product controls.
